# Проект Участка Кербуково

- [Открыть 3D-прогулку](https://ultrozing-ops.github.io/kerbukovo/)
- [Скачать автономную версию](https://ultrozing-ops.github.io/kerbukovo/kerbukovo-offline.zip)

Распакуйте ZIP и откройте `index.html` в браузере с WebGL 2. Для автономной версии интернет не требуется.

**Обзор** — поворачивайте модель перетаскиванием, масштабируйте колесом.
**Прогулка** — используйте W A S D или стрелки. Поворачивайте взгляд мышью с нажатой кнопкой. На сенсорном экране есть кнопки направления.
**План** — смотрите сверху и приближайте нужный объект.
**Пометки** — нажмите «Пометка», укажите точку и сохраните текст. На вкладке «Пометки» есть экспорт JSON, импорт и копирование ссылки. Данные хранятся в браузере.

Это эскиз. Въезд принят за 0,0 м, левый край за −2,0 м. Расстояние между длинными стенками контейнеров — 4,5 м. Бытовка стоит в 5 м влево вдоль забора от ближнего контейнера. Габарит 8 × 8,5 м включает крыльцо. Баня развёрнута длинной стороной вдоль забора, с отступом 1 м, входом с южной стороны и крыльцом на линии крыльца дома. Электроопора и ели показаны снаружи. Полоса чернозёма — 15 м. Пространство вокруг участка доступно для прогулки и пометок. Глубина 1,50 м на эскизе относится ко дну траншеи. Фактические привязки, сети и высотные отметки проверяются перед работами.

## Сборка

`npm install` устанавливает зависимости. `npm run build` собирает статическое приложение в `docs/app.js`. GitHub Pages публикует папку `docs` ветки `main`.
