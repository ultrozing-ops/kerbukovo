# Проект Участка Кербуково

- [Открыть 3D-прогулку](https://ultrozing-ops.github.io/kerbukovo/)
- [Скачать один HTML-файл для телефона](https://github.com/ultrozing-ops/kerbukovo/releases/latest/download/kerbukovo-mobile.html)
- [Скачать автономную версию ZIP](https://ultrozing-ops.github.io/kerbukovo/kerbukovo-offline.zip)

Откройте скачанный HTML-файл в браузере с WebGL 2. Если выбран ZIP, распакуйте его и откройте `index.html`. Для этих файлов интернет не требуется.

На iPhone откройте страницу в Safari. В меню «Поделиться» выберите «На экран “Домой”» и откройте приложение с иконки первый раз с интернетом. Когда меню «Скачать» покажет готовность к работе без сети, модель открывается и автономно.

**Обзор** — поворачивайте модель перетаскиванием, масштабируйте колесом.
**Прогулка** — используйте W A S D или стрелки. Поворачивайте взгляд мышью с нажатой кнопкой. На сенсорном экране есть кнопки направления.
**План** — смотрите сверху и приближайте нужный объект.
**Пометки** — нажмите «Пометка», укажите точку и сохраните текст. На вкладке «Пометки» есть экспорт JSON, импорт и копирование ссылки. Данные хранятся в браузере.

Это эскиз. Въезд принят за 0,0 м, левый край за −2,0 м. Расстояние между длинными стенками контейнеров — 4,5 м. Бытовка стоит в 5 м влево вдоль забора от ближнего контейнера. Габарит 8 × 8,5 м включает крыльцо. Баня развёрнута длинной стороной вдоль забора, с отступом 1 м, входом с южной стороны и крыльцом на линии крыльца дома. Электроопора и ели показаны снаружи. Полоса чернозёма — 15 м. У бытовки зелёная односкатная крыша. Биотуалет стоит внутри у нижнего забора напротив опоры. Слева показано пшеничное поле. Справа вдоль забора проходит дорога шириной 7 м, дальше — небольшой лес. Пространство вокруг участка доступно для прогулки и пометок. Глубина 1,50 м на эскизе относится ко дну траншеи. Фактические привязки, сети и высотные отметки проверяются перед работами.

## Сборка

`npm install` устанавливает зависимости. `npm run build` собирает `docs/app.js` и автономный `docs/kerbukovo-mobile.html`. При выпуске версии обновите имя кэша в `docs/sw.js`. GitHub Pages публикует папку `docs` ветки `main`.
